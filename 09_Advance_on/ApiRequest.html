Value State Description
0 UNSENT The object has been constructed, but the open() method has not been called yet.
1 OPENED The open() method has been successfully invoked, but the send() method has not been called.
2 HEADERS_RECEIVED The send() method has been called, and all HTTP headers of the response have been received. The response body is not yet available.
3 LOADING The response body is being received. Partial data may be available in responseText (though not universally supported).
4 DONE The data transfer has been completed, and the response is ready for processing, whether the request succeeded or failed.
